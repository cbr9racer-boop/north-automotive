North Automotive LLC — static site for Porkbun

Unzip this, then upload the FILES INSIDE (not the zip, and not an extra folder).
index.html must sit in the website root.

Porkbun:
1. Domain Management → house icon under Website → Static Hosting.
2. Upload these files with the editor, or by FTP (credentials under Publishing).
3. Open https://your-domain/ and click Services, About, NAPA AutoCare, and Contact.

The contact form opens the visitor's email app addressed to northautomotivellc@yahoo.com.
It does not store messages on the server.
